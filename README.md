# 🚨 Emergency Hotlines

A simple and user-friendly emergency services web application that helps users quickly find important emergency hotline numbers in Bangladesh. Users can view emergency service information, copy hotline numbers, and make calls directly from the application.

## 📖 About The Project

**Emergency Hotlines** is a responsive web application designed to provide quick access to important emergency contact numbers.

The application presents different emergency services in an easy-to-use interface so users can quickly find the service they need during an emergency.

## 🛠️ Technologies Used

* **HTML5** — Semantic page structure
* **CSS3** — Styling and responsive design
* **JavaScript (ES6)** — Application logic and interactions
* **DOM Manipulation** — Dynamic content and user interactions
* **Font Awesome / Icons** — User interface icons
* **Git & GitHub** — Version control and hosting
* **GitHub Pages** — Deployment

## ✨ Key Features

### 🚑 Emergency Service Directory

Users can browse important emergency services and their corresponding hotline numbers.

### 📞 Quick Call

Users can directly call an emergency service by clicking the call button.

### 📋 Copy Hotline Number

Users can copy emergency hotline numbers to their clipboard for quick access.

### ❤️ Favorite Services

Users can mark frequently used emergency services as favorites for easier access.

### 🔢 Call History

The application keeps track of recently called emergency services so users can easily review their previous calls.

### 📱 Responsive Design

The application works smoothly across:

* 📱 Mobile devices
* 📲 Tablets
* 💻 Laptops
* 🖥️ Desktop computers

JavaScript and DOM manipulation are used to provide a smooth and interactive user experience.

## ⚙️ How To Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/code-by-nusrat/emergency-hotlines.git
```

### 2. Navigate to the project folder

```bash
cd emergency-hotlines
```

### 3. Open the project

You can open `index.html` directly in your browser.

For a better development experience, you can use **VS Code Live Server**.

### 4. Run with Live Server

If you have the Live Server extension installed in VS Code:

1. Open the project in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.

The project will open in your browser.
